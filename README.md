# ClientTempo marketing

Public marketing site for ClientTempo. It does not share code, accounts, or services with the product application.

## Develop

```bash
npm install
npm run dev
```

## Point signup and sign-in at the product

Sign In and Start Free open `https://app.clienttempo.com/sign-in` and `/sign-up`. To point a build at a different app, set `NEXT_PUBLIC_APP_ORIGIN` to that origin, with no trailing slash. See `.env.example` and `lib/site.ts`.
